# Лексияҳо (маводи таълимӣ)

Ин ҷузвдон маводи таълимии тиббиро нигоҳ медорад. Ҳоло дар он:

## Камхуниҳои гемолитикии модарзодӣ (ирсӣ) — лексияи 3-соата

| Файл | Тавсиф |
|---|---|
| **[kamkhunii-hemolitikii-modarzodi.md](kamkhunii-hemolitikii-modarzodi.md)** | Матни асосии лексия (Markdown) — 13 қисм: мафҳумҳо, патогенез, мембранопатияҳо, G6PD/PK, талассемия, камхунии ҳуҷайраҳои досма, алгоритми ташхис, табобат, мисолҳои клиникӣ, тестҳо, глоссарий |
| **[kamkhunii-hemolitikii-modarzodi.html](kamkhunii-hemolitikii-modarzodi.html)** | Ҳамон лексия дар шакли HTML (барои хондан дар браузер ва чоп ба A4; расмҳо дохил карда шудаанд) |
| **[pamyatka-1-safha.md](pamyatka-1-safha.md)** | Памяткаи кӯтоҳ (1–2 саҳифа) барои такрор ва ҷайб |

| `build_html.py` | Скрипти табдили Markdown → HTML (`python3 build_html.py`; талаб: `pip install markdown`) |

### Сохтори лексия (барои дарс)

- **Блок I (45 дақ.):** мафҳумҳо, эритропоэз, гемолиз, классификатсия, механизмҳои умумӣ, клиника ва лабораторияи гемолиз
- **Блок II (45 дақ.):** мембранопатияҳо (HS, HE, PNH) + ферментопатияҳо (G6PD, PK)
- **Блок III (45 дақ.):** талассемия + камхунии ҳуҷайраҳои досма, алгоритми ташхис, табобат, терапияи генетикӣ, ҷамъбаст
- Танаффус — 10 дақ.; ҷамъбаст ва тестҳо — 15–20 дақ.

> ⚠️ Маводи таълимӣ. Дар амалияи клиникӣ протоколҳои миллии клиникӣ ва дастурамалҳои расмии доруҳоро истифода баред.
