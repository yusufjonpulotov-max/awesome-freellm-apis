# ПАМЯТКА (як-ду саҳифа барои такрор ва ҷайб)

## Лексия: Камхуниҳои гемолитикии модарзодӣ — ҳама чиз дар як назар

---

## 1. ТРИАДАИ ГЕМОЛИЗ (ҳатман дар ёд!)

> **Ретикулотситҳо ↑ + билирубини ғайримустақим ↑ + LDH ↑**

Илова ба онҳо:
- **Гаптоглобин ↓↓↓**, гемоглобинурия, гемоглобинемия → **интраваскулярӣ**
- **Спленомегалия**, сферотситҳо, фагоцитоз дар макрофагҳо → **экстраваскулярӣ**
- **DAT (Кумбс) мусбат → иммунӣ** (аквизитсия) · **DAT манфӣ → ирсӣ** (модарзодӣ)

---

## 2. ҶАДВАЛИ КАЛИДӢ: 6 бемориро чӣ тавр фарқ кунем

| Беморӣ | Ирс | Синну сол | MCV | MCHC | Морфология | Таҳлили калидӣ | Табобати калидӣ |
|---|---|---|---|---|---|---|---|
| **Микросферотситоз (HS)** | АД | кӯдакӣ | N | **↑** | сферотситҳо | **EMA-binding (+)** | фолат, спленэктомия |
| **Эллиптотситоз (HE)** | АД | ҳар вақт | N | N | эллиптотситҳо > 25 % | EMA-binding (−) | фолат (одатан ҳеҷ) |
| **Нуқсони G6PD** | **X-аллоқаманд** | пас аз триггер | N | N | bite cells, Heinz | фаъолияти G6PD ↓ (баъд аз 2–3 моҳ!) | пешгирӣ, трансфузия |
| **Нуқсони PK** | АР | кӯдакӣ | N | N | кам | фаъолияти PK ↓ | фолат, **митапиват** |
| **Талассемияи β** | АР | 3–6 моҳ | **↓** | N | target, базофилия | **HbA₂ ↑ / HbF ↑** | трансфузия + хелат |
| **Камхунии ҳуҷайраҳои досма** | АР | 4–6 моҳ | N | N | **ҳуҷайраи досма**, Howell-Jolly | **HbS дар HPLC** | hydroxyurea, генетикӣ |

**Индекси Mentzer = MCV ÷ RBC:** `< 13` → талассемия · `> 13` → камбуди оҳан.

## 3. ЗАНҶИРАҲОИ ПАТОГЕНЕТИКӢ (дар 1 сатр)

| Беморӣ | Занҷира |
|---|---|
| **HS** | мутацияи ANK1/SPTB/SLC4A1 → пайванди вертикалӣ суст → талафи мембрана → сферотсит → ҳабс дар сипурз → фагоцитоз → гемолизи экстраваскулярӣ |
| **HE** | мутацияи SPTA1/SPTB → пайванди уфуқӣ суст → эллиптотсит → гемолизи сабук |
| **G6PD** | NADPH ↓ → GSH ↓ → H₂O₂ ҷамъ → **Heinz** → bite cells → гемолизи интраваскулярӣ |
| **PK** | ATP ↓ → насосҳо суст → дегидрататсия → гемолиз |
| **Талассемияи β** | β кам → **избытоки α** → пресипитатсия дар эритробласт → **эритропоэзи номуассир** + гемолизи периферӣ → гиперплазияи мағзи устухон → сарбории оҳан |
| **Талассемияи α** | α кам → избытоки β/γ → **HbH (β₄) / Hb Bart's (γ₄)** → гемолизи периферӣ |
| **Камхунии ҳуҷайраҳои досма** | Glu6Val → дезоксигенатсия → **полимеризатсия** → досмашаклшавӣ → дегидрататсия (Gardos) → **васоокклюзия** + гемолиз → NO ↓ → кризҳо |

## 4. ТРИГГЕРҲОИ НУҚСОНИ G6PD (рӯйхати манъ)

| Гурӯҳ | Намунаҳо |
|---|---|
| **Доруҳо** | примаквин, памаквин, тафенохин, **дапсон**, нитрофурантоин, **сулфаниламидҳо (котримоксазол)**, метиленсиний, аспирин (> 1 г), кислотаи аскорбинӣ (миқдори калон) |
| **Хӯрок** | **лӯбиёи бақилла (фавизм)** |
| **Сироятҳо** | гепатит, пневмония, семпсис, грипп (40–50 % ҳолатҳо) |
| **Дигар** | кетоацидоз, **нафталин**, **ҳеннӣ**, гипоксия, ҳомиладорӣ |

---

## 5. ҲОЛАТҲОИ ФАВҚУЛОДДА (ташхис → тадбир)

| Ҳолат | Нишонаҳои хос | Тадбир |
|---|---|---|
| **Кризи гемолитикӣ** (G6PD, HS) | пешоби тор, зардӣ, Hb ↓↓, ретикулотситҳо ↑ | гидрататсия, диурез, трансфузия (Hb < 70 г/л) |
| **Кризи апластикӣ** (парвовирус B19) | ретикулотситҳо **< 1 %**, Hb якбора ↓ | трансфузия, ҳимоя |
| **Кризи секвестратсия** (SCD) | сипурзи калон, шок | трансфузия, дастгирии ҳамодинамикӣ |
| **VOC** (SCD) | дарди шадиди устухон/шикам | **гидрататсия + опиоидҳо** (таъхир манъ!), муоина ҳар 2–4 соат |
| **ACS** (SCD) | табларза, дарди сина, инфилтрат | оксиген, антибиотикҳо, трансфузия/exchange |
| **Инсулт** (SCD) | гемиплегия, афазия | **exchange transfusion**, MRI/MRA |
| **Криз дар талассемия** | Hb ↓, ниёз ба трансфузия | трансфузия, назорати ферритин |

## 6. ТАБОБАТ ДАР ЯК НАЗАР

| Гурӯҳ | Асос | Нишонаҳои махсус |
|---|---|---|
| **HS / HE** | фолат 1–5 мг/рӯз | спленэктомия (баъд аз ваксинатсия + пенитсиллин) |
| **G6PD** | пешгирии триггерҳо | трансфузия ҳангоми криз; **кортикостероидҳо бемаънӣ** |
| **Табобати талассемия** | трансфузия + **хелатотерапия** | деферасирокс / деферипрон (барои дил) / дефероксамин; HSCT; **Casgevy**; luspatercept; mitapivat |
| **Камхунии ҳуҷайраҳои досма** | **hydroxyurea** (HbF ↑) + фолат + ваксинатсия + пенитсиллин | трансфузия/exchange, HSCT, **Casgevy / Lyfgenia** |

**Спленэктомия — ҳатман:** ваксинатсия зидди **пневмококк, Hib, менингококк** 2–4 ҳафта пеш + **пенитсиллини профилактикӣ** баъд аз амалия.
**Дар ксеротситоз (PIEZO1/KCNN4) спленэктомия МАНЪ аст!**

## 7. 12 РАҚАМҲОИ МУҲИМ

| Рақам | Маъно |
|---|---|
| **100–120 рӯз** | умри муқаррарии эритротсит |
| **0,5–1,5 %** | ретикулотситҳои меъёр |
| **> 360 г/л** | MCHC — нишони HS |
| **> 3,5 %** | HbA₂ — нишони талассемияи β (trait) |
| **< 13** | индекси Mentzer — самти талассемия |
| **< 1 %** | ретикулотситҳо — кризи апластикӣ |
| **< 70 г/л** | нишони трансфузия дар кризи гемолитикӣ |
| **< 1–10 %** | фаъолияти G6PD (класси II — вазнин) |
| **80–95 %** | фоизи HbS дар HbSS |
| **> 90 %** | беморони Casgevy бе кризи VOC |
| **T2\* > 20 мс** | меъёри оҳани дил (хавфи баланд < 10 мс) |
| **< 1000 мкг/л** | ферритин — ҳадафи хелатотерапия |
